# Saloe CMS - Vite.js Project

A simple and elegant Vite.js project with plain CSS styling.

## Features

- ⚡ Fast development with Vite.js
- 🎨 Beautiful, responsive design
- 📱 Mobile-friendly layout
- 🎭 Smooth animations and transitions
- 🔧 Simple setup and configuration

## Getting Started

### Prerequisites

Make sure you have Node.js installed on your system (version 14 or higher).

### Installation

1. Install dependencies:
```bash
npm install
```

### Development

Start the development server:
```bash
npm run dev
```

This will start the development server at `http://localhost:3000` and automatically open your browser.

### Building for Production

Build the project for production:
```bash
npm run build
```

The built files will be in the `dist` directory.

### Preview Production Build

Preview the production build locally:
```bash
npm run preview
```

## Project Structure

```
saloe-cms/
├── index.html          # Main HTML entry point
├── src/
│   ├── main.js        # Main JavaScript file
│   └── style.css      # CSS styles
├── package.json        # Project dependencies and scripts
├── vite.config.js     # Vite configuration
└── README.md          # This file
```

## Customization

- Edit `src/style.css` to modify the styling
- Update `index.html` to change the content
- Modify `src/main.js` to add more interactivity

## Technologies Used

- [Vite.js](https://vitejs.dev/) - Fast build tool and development server
- Vanilla JavaScript - No framework dependencies
- Plain CSS - Modern styling with gradients and animations
